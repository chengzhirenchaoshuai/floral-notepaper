# 花笺自用版 v1.2.2

仅提供 Windows x64。

## 新增

- 便携版支持应用内更新：发现新版本后可直接下载、替换并重启，exe 的位置和文件名保持不变，替换失败会自动恢复旧版；exe 所在目录不可写入时（如只读 U 盘），改为提供“打开下载页”按钮
- Markdown 预览保留段落内的单个换行，逐行书写的内容不再挤成一行；可在设置中关闭，默认开启
- 磁贴渲染 Markdown 时同样渲染内嵌 HTML，与主窗口预览一致

## 优化

- 预览始终渲染内嵌 HTML（仍会过滤脚本等危险内容），设置中移除“允许 HTML 标签渲染”开关
- 本地图片读取失败时显示 `[图片说明]` 占位，鼠标悬停可查看完整路径

## 修复

- 路径含中文或空格的本地图片无法显示
- 点击设置中靠下的开关（如自动更新）后，整个设置面板变成空白
- 移除对不存在的思源宋体粗体字体的引用

## 自用版调整

- 界面语言只保留简体中文，设置中移除语言切换
- 关于页贡献者改为固定名单，构建时不再联网拉取
- 清理 Mirror酱、MSIX/Microsoft Store 与非 Windows 平台的遗留代码，并拆分主窗口代码，便于后续维护

## 升级提示

v1.2.1 便携版不支持应用内更新，请手动下载本版便携版替换旧文件，笔记数据不受影响；从 v1.2.2 起便携版可在应用内自动更新。安装版可直接在应用内更新。
