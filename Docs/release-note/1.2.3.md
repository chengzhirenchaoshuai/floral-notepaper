# 花笺自用版 v1.2.3

仅提供 Windows x64。

## 新增

- 隐藏模式：在设置中开启后，不显示托盘图标，关闭主窗口时程序在后台常驻，再打开 md 文件时直接复用已加载好的窗口，省去冷启动，打开更快；配合“开机自启”效果最好，默认关闭
- 隐藏模式下设置页提供“退出程序”按钮，用来完全退出程序；重新运行 exe 或按显示/隐藏快捷键可以唤出主窗口

## 优化

- 隐藏模式开启时，关闭主窗口总是常驻后台，设置页不再显示“关闭到托盘”开关；关闭隐藏模式后恢复显示，并沿用原来的设置

## 升级提示

安装版和便携版（v1.2.2 起）都可以直接在应用内更新，笔记数据不受影响。
