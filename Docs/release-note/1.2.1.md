# 花笺自用版 v1.2.1

基于官方 v1.2.0 的首个自用版本，仅提供 Windows x64。

## 新增

- 设置中新增“界面设置”页：可选择界面字体、调整编辑器与小窗/磁贴字号、设置界面背景色（上游 PR #306）
- 记住主窗口大小和位置，可在设置中关闭（上游 PR #306）
- 快捷便签小窗置顶改为可配置，默认仍置顶（上游 PR #346）
- 编辑器工具栏新增“插入本地图片”按钮，可一次选择多张图片插入
- 外部 Markdown 文档中的本地图片可正常显示；启动时可直接收起侧栏

## 优化

- Markdown 预览：单个波浪号不再渲染为删除线；支持 HTML `align` 对齐；单张图片段落居中显示
- 启动时不再出现侧栏“先展开再收起”的动画

## 修复

- 便签池预热时多余的隐藏 WebView 未被关闭的问题（上游 PR #316）

## 自用版调整

- 应用内更新只检查本仓库的 GitHub Release，不再使用 Mirror酱
- 移除 macOS、Linux、ARM64、MSIX 与 Microsoft Store 版本
- 安装包与便携版未做代码签名，首次运行时 SmartScreen 可能提示，选择“仍要运行”即可
